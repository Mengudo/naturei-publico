# Naturei — arquivos públicos

Repositório público com o que o app **Naturei** precisa acessar sem login. O código do app fica num repositório privado.

- **`privacidade.html`**: a política de privacidade do app, publicada pelo GitHub Pages em
  https://mengudo.github.io/naturei-publico/privacidade.html
- **Releases**: cópias sem modificação de modelos de terceiros que o app baixa no primeiro uso.
  - `birdnet-v3.0-preview3.1`: o modelo de áudio BirdNET+ V3.0-preview3.1. Ele é do BirdNET Team, do Cornell Lab of Ornithology e da TU Chemnitz, com licença Apache 2.0. Os detalhes estão nas notas da release.
- **`version.json`** — só o número da versão mais recente do app; o Naturei consulta este arquivo para avisar "Nova versão disponível". O APK do app não é publicado aqui (é distribuído em particular).
